# Brian Sule Portfolio

A static portfolio page. `index.html` and the `.webp` images sit together in one folder. No build step is needed.

## Update your existing GitHub repository

1. Open your repository on github.com.
2. Click **Add file > Upload files**.
3. Drag in `index.html` and all the `.webp` images from this folder. Files with the same name replace the old ones.
4. Click **Commit changes**. The site refreshes in a minute or two. Press Ctrl+Shift+R (Cmd+Shift+R on Mac) to see the new version.

## Optional clean-up

The earlier version used these images, which this page no longer needs. You can leave them or delete them
(open the file, click the trash icon, commit): ai-1 to ai-5, wal-1 to wal-4, b2b-1 to b2b-6 (all `.webp`).

and you upload the new `index.html` the same way.
